# DARK EDITING AND WEBSITE

Luxury dark/gold 3D animated website for video editing & web design agency.

## Quick Start

```bash
npm install
npm run dev
```

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/DARK5trillion/Dark-editing-website)

## Features

- Hero: 15k gold particles forming animated logo badge
- Services: 8 magnetic glass cards in 3D space
- Pricing: 5 interactive tier cards with gold shimmer
- Contact: Liquid gold WhatsApp/Instagram buttons
- WebGPU with WebGL2 fallback
- WCAG 2.2 AAA compliant
